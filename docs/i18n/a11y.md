# Accessibility and Localization Verification

## English baseline

- `tests/e2e/08-a11y.spec.ts` runs axe (`wcag2a`/`wcag2aa`) on the dashboard and the company form.
- Run it after the auth setup spec, because the E2E suite assumes `01-auth.spec.ts` creates the workspace admin:

```bash
pnpm test:e2e tests/e2e/01-auth.spec.ts tests/e2e/08-a11y.spec.ts
```

## Greek baseline

- `tests/e2e/09-localization.spec.ts` covers the Greek journey and the Greek accessibility baseline.
- It asserts `lang="el"`, localized navigation/search/close names, keyboard operation of the mobile navigation, focus returning to the trigger after Escape, and axe (`wcag2a`/`wcag2aa`).
- Latest result: 0 total axe violations, 0 serious or critical, on the Greek dashboard.

```bash
pnpm test:e2e tests/e2e/01-auth.spec.ts tests/e2e/09-localization.spec.ts
```

## Full suite

```bash
pnpm test:e2e
```

The suite runs serially. `01-auth.spec.ts` creates the admin and the ordered specs build on that state. A standalone run of a later spec on a freshly prepared database is expected to fail at sign-in until the auth spec has run.
